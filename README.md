# WEB LEVONTEA

Project landing page Le Vontea.

## Struktur folder

Semua file utama berada langsung di folder `WEB LEVONTEA`.

```text
WEB LEVONTEA/
├── app/
├── public/
├── package.json
├── server.mjs
└── next.config.mjs
```

## Menjalankan

Buka PowerShell dan masuk ke folder:

```powershell
cd "C:\Users\Tri Gutomo\Downloads\WEB LEVONTEA"
```

Pertama kali saja:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm install
```

Jalankan website:

```powershell
node server.mjs
```

Buka Chrome:

http://localhost:3000

## Saat ada revisi

Tekan `Ctrl + C`, kemudian jalankan lagi:

```powershell
node server.mjs
```
